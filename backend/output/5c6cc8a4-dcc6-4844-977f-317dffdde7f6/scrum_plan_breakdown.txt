## ⚠️ **Risks & Impediments**

| Risk / Impediment | Impact | Mitigation Strategy |
|--------------------|---------|--------------------|
| **Email reset link delivery delay** if SMTP provider throttles | Medium | Use tested enterprise SMTP with retry/backoff; prevalidate domain whitelist |
| **Lockout duration tuning may frustrate users** | Medium | Make lockout configurable (e.g., via properties) and monitor early feedback |
| **Session token lifecycle issues causing premature logout** | High | Clear contract between API and frontend for token TTL; implement silent refresh |
| **Auditing overload on Kafka** | Low | Batch audit events or use async send with buffering |
| **Rate limit misconfiguration affecting legitimate users** | Medium | Use IP + username-based buckets and log threshold breaches for tuning |
| **Security compliance drift** (password strength, encryption) | High | Review implementation versus current infosec baseline before deployment |
