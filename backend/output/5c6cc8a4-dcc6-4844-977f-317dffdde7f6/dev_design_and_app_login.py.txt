## 🧩 **Concise Technical Design**

**Framework:**  
- **Backend:** Flask (micro‑framework for Python)  
- **Form Handling & CSRF Protection:** `Flask‑WTF`  
- **Password Hashing:** `bcrypt` (`bcrypt` library)  
- **Templating:** default Jinja2 rendered HTML templates (minimal inline form for demo)

**Routing:**
- `/login` – GET: render login form  
- `/login` – POST: validate credentials, set session  
- `/logout` – GET: clear session (optional)  

**Auth Flow:**
1. User requests `/login` (GET) → server returns CSRF‑protected form.  
2. User posts username/password → form validation occurs (non‑empty fields).  
3. Password comparison using bcrypt hash.  
4. If correct: session variable `user` set; redirect to a dummy dashboard (for now).  
5. If incorrect: show validation error.  

**Security Aspects:**
- CSRF tokens automatically injected via Flask‑WTF.  
- Passwords stored hashed (never plaintext).  
- Session cookie secured (`HttpOnly`, optional `Secure` in production).  
- Fake in‑memory user store for MVP (dict in code).

## 📁 **Code Skeleton**

Below is one single Python file named **`app_login.py`**.

```python
"""
app_login.py
-------------
Minimal Flask login application demonstrating secure authentication flow:
 - CSRF protection using Flask-WTF
 - Password hashing with bcrypt
 - Form validation with WTForms
 - Fake in-memory user store

This skeleton can be extended with real templates, database access,
and proper session management.
"""

from flask import Flask, render_template_string, request, redirect, url_for, session, flash
from flask_wtf import FlaskForm, CSRFProtect
from wtforms import StringField, PasswordField, SubmitField
from wtforms.validators import DataRequired
import bcrypt  # for password hashing

# -------------------------------------------------------------
# Flask and Security Setup
# -------------------------------------------------------------
app = Flask(__name__)
app.secret_key = "change_this_in_production"  # required for sessions & CSRF
csrf = CSRFProtect(app)
csrf.init_app(app)

# -------------------------------------------------------------
# In-memory fake user store
# (in production, this would be a user database or identity service)
# -------------------------------------------------------------
# Store bcrypt-hashed passwords
fake_users = {
    "alice": bcrypt.hashpw(b"Password123", bcrypt.gensalt()),
    "bob": bcrypt.hashpw(b"SecurePass!", bcrypt.gensalt()),
}

# -------------------------------------------------------------
# WTForms LoginForm Definition
# -------------------------------------------------------------
class LoginForm(FlaskForm):
    username = StringField("Username", validators=[DataRequired()])
    password = PasswordField("Password", validators=[DataRequired()])
    submit = SubmitField("Login")

# -------------------------------------------------------------
# Routes
# -------------------------------------------------------------
@app.route("/login", methods=["GET", "POST"])
def login():
    form = LoginForm()
    if form.validate_on_submit():
        username = form.username.data.strip().lower()
        password = form.password.data.encode("utf-8")

        # Check user existence
        if username in fake_users:
            stored_hash = fake_users[username]
            # Verify password
            if bcrypt.checkpw(password, stored_hash):
                session["user"] = username
                flash("Login successful!", "success")
                return redirect(url_for("dashboard"))
            else:
                flash("Invalid password.", "danger")
        else:
            flash("Unknown username.", "danger")

    # Minimal inline HTML template for demonstration
    return render_template_string(
        """
        <!doctype html>
        <html>
        <head><title>Login</title></head>
        <body>
          <h2>Secure Login</h2>
          {% with messages = get_flashed_messages(with_categories=true) %}
            {% if messages %}
              <ul>
                {% for category, message in messages %}
                  <li style="color:red;">{{message}}</li>
                {% endfor %}
              </ul>
            {% endif %}
          {% endwith %}

          <form method="POST">
            {{ form.hidden_tag() }}
            <p>{{ form.username.label }} {{ form.username(size=32) }}</p>
            <p>{{ form.password.label }} {{ form.password(size=32) }}</p>
            <p>{{ form.submit() }}</p>
          </form>
        </body>
        </html>
        """,
        form=form,
    )

@app.route("/dashboard")
def dashboard():
    # Dummy protected page for demonstration
    user = session.get("user")
    if not user:
        flash("Please log in first.", "warning")
        return redirect(url_for("login"))
    return f"<h3>Welcome, {user}!</h3><a href='{url_for('logout')}'>Logout</a>"

@app.route("/logout")
def logout():
    session.pop("user", None)
    flash("Logged out.", "info")
    return redirect(url_for("login"))

# -------------------------------------------------------------
# Entry Point
# -------------------------------------------------------------
if __name__ == "__main__":
    # In production, use gunicorn or similar and set secure cookie attributes
    app.run(debug=True)
```

### ✅ Key Notes
- **CSRFProtect** ensures no forged form submits.  
- **bcrypt** used for password hashing and verification.  
- **WTForms validators** (`DataRequired`) prevent blank fields.  
- **In-memory fake user store** simulates a backend user DB for MVP.  
- Extend later with JWT sessions, OAuth2 identity provider, rate-limiting, etc.
