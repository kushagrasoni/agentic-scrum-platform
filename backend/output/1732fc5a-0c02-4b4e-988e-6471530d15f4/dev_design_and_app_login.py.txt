## 🔧 Technical Design (Concise)

**Frameworks / Libraries**
- **Flask** – lightweight web framework
- **Flask-WTF** – HTML form handling + CSRF protection
- **WTForms** – built-in validators
- **bcrypt** – secure password hashing
  
**Routing**
- `/login` (GET): renders login form  
- `/login` (POST): validates credentials, authenticates user  
- (optional) `/dashboard`: placeholder for post-login landing
  
**Authentication Flow**
1. Flask-WTF creates form (`LoginForm`) with CSRF token.
2. On POST, server validates form data.
3. User store: in-memory dictionary (username → bcrypt-hash).
4. Compare submitted password using `bcrypt.checkpw`.
5. If valid → create session; otherwise → flash error.
6. Protect endpoints by checking `session['user']`.
7. CSRF enabled globally for all forms.

## 🧩 Code Skeleton — `app_login.py`

```python
"""
app_login.py
-------------
Minimal Flask application demonstrating:
 - Login page with CSRF protection
 - Form validation (WTForms)
 - Password hashing using bcrypt
 - Fake in-memory user store
"""

from flask import Flask, render_template_string, request, redirect, url_for, flash, session
from flask_wtf import FlaskForm, CSRFProtect
from wtforms import StringField, PasswordField, SubmitField
from wtforms.validators import DataRequired, Length
import bcrypt

# ---------------------------------------------------------------------------
# App Initialization
# ---------------------------------------------------------------------------
app = Flask(__name__)
app.secret_key = "dev_secret_key"  # In production, use secure secret!
csrf = CSRFProtect(app)

# ---------------------------------------------------------------------------
# Fake user store with bcrypt-hashed passwords
# For demonstration only – replace with DB or IAM integration
# ---------------------------------------------------------------------------
def create_user_store():
    password_plain = b"password123"
    password_hash = bcrypt.hashpw(password_plain, bcrypt.gensalt())
    # In-memory dictionary mapping username -> hashed password
    return {"alice": password_hash}

USER_STORE = create_user_store()


# ---------------------------------------------------------------------------
# Login form definition using Flask-WTF + WTForms
# ---------------------------------------------------------------------------
class LoginForm(FlaskForm):
    username = StringField(
        "Username",
        validators=[DataRequired(), Length(min=3, max=64)]
    )
    password = PasswordField(
        "Password",
        validators=[DataRequired(), Length(min=8, max=128)]
    )
    submit = SubmitField("Login")


# ---------------------------------------------------------------------------
# Routes
# ---------------------------------------------------------------------------
@app.route("/login", methods=["GET", "POST"])
def login():
    form = LoginForm()
    if form.validate_on_submit():
        username = form.username.data
        password = form.password.data.encode("utf-8")

        # Validate user
        user_hash = USER_STORE.get(username)
        if user_hash and bcrypt.checkpw(password, user_hash):
            session["user"] = username
            flash("Login successful!", "success")
            return redirect(url_for("dashboard"))
        else:
            flash("Invalid username or password", "error")

    # Simple inline template for demonstration
    return render_template_string("""
        <!doctype html>
        <html lang="en">
          <head>
            <meta charset="utf-8"/>
            <title>Login Page</title>
          </head>
          <body>
            <h2>Login</h2>
            <form method="POST">
              {{ form.hidden_tag() }}
              <p>{{ form.username.label }} {{ form.username() }}</p>
              <p>{{ form.password.label }} {{ form.password() }}</p>
              <p>{{ form.submit() }}</p>
            </form>
            {% with messages = get_flashed_messages(with_categories=true) %}
              {% if messages %}
                <ul>
                {% for category, message in messages %}
                  <li><strong>{{ category }}:</strong> {{ message }}</li>
                {% endfor %}
                </ul>
              {% endif %}
            {% endwith %}
          </body>
        </html>""", form=form)


@app.route("/dashboard")
def dashboard():
    # Require login
    if "user" not in session:
        flash("Please log in to access dashboard", "error")
        return redirect(url_for("login"))
    return f"Welcome, {session['user']}! You are logged in."


# ---------------------------------------------------------------------------
# Entry point
# ---------------------------------------------------------------------------
if __name__ == "__main__":
    app.run(debug=True)
```

---

### ✅ Notes
- **CSRF protection** via Flask-WTF and `hidden_tag()`.
- **Form validation** ensures required fields and length constraints.
- **bcrypt hashing** used both for storing and verifying passwords.
- **Session handling** uses Flask’s secure cookie-based sessions.
- Code is suitable as a minimal starting point; replace secrets and user store before production.
